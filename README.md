# easytimer

An ultra-lightweight and intuitive visual countdown built to keep workshops, meetings, and presentations strictly on track.

## Features

- Countdown mode and session mode
- Fullscreen timer with responsive mobile layout
- Ad-hoc timer controls with start/pause/reset
- Menu for theme selection and timer mode
- No dependencies, runs directly in the browser

## Usage

1. Open `src/index.html` in your browser.
2. Use the menu to select `Normal countdown` or `Session mode`.
3. Start the timer with the control buttons.
4. Use the ad-hoc section for flexible time intervals.

## Development

- `src/index.html` – main layout and UI markup
- `src/css/styles.css` – styles and responsive layout rules
- `src/js/app.js` – app logic, timer control, and UI interactions

## Project structure

- `src/index.html`
- `src/css/styles.css`
- `src/js/app.js`
- `docs/` – project documentation and briefing notes

## Notes

- The app does not require a local server, but it can also be served from a simple static server.
- Changes to CSS and JavaScript can be tested directly from the `src` folder.
