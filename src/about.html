About easyTimer

Plan less. Time better.

Create a Rundown and keep your event on time.

A private, free tool

easyTimer is a free, noncommercial timer developed as a personal project for workshops, meetings and presentations.

Quick timeboxes and timed events

Use Quick Timer for individual timeboxes. Create reusable Event Templates with named phases in the Event Editor. Start Event opens an independent event in the Event Timer. Phase 1 stays READY until you press Start. Phase transitions can be manual or automatic.

Local, without an account

Event Templates, independent events, preferences and timer recovery are stored in this browser. Export one Event Template for sharing or download all native local data as JSON. Full local-data restore is not yet supported. Google Account and Google Drive are not part of this public release.

Über easyTimer

Plan less. Time better.

Erstelle einen Rundown und behalte die Zeit für dein Event im Blick.

Ein privates, kostenloses Werkzeug

easyTimer ist ein kostenloser, nichtkommerzieller Timer, der als privates Projekt für Workshops, Meetings und Präsentationen entwickelt wird.

Kurze Timeboxes und zeitlich geplante Events

Nutze den Quick-Timer für einzelne Timeboxes. Erstelle im Event-Editor wiederverwendbare Event-Templates mit benannten Phasen. Event starten öffnet ein eigenständiges Event im Event-Timer. Phase 1 bleibt bereit, bis du Starten drückst. Phasenwechsel können manuell oder automatisch erfolgen.

Lokal, ohne Konto

Event-Templates, eigenständige Events, Einstellungen und Timer-Wiederherstellung werden in diesem Browser gespeichert. Teile einzelne Event-Templates oder lade alle nativen lokalen Daten als JSON herunter. Eine vollständige Wiederherstellung des lokalen Datenexports wird noch nicht unterstützt. Google Account und Google Drive gehören nicht zu dieser öffentlichen Release-Fassung.
